## 点点与 xiaoliu 能否同时运行（13:25 实测）

**能同时跑，进程与服务端层面完全共存；但「两个都开着听语音」会互相打架。**

实测：点点（`Diandian.Windows.App.exe`，PID 49296，69 线程/208MB）与 xiaoliu（PID 82972）同时运行，
点点成功接入本机服务端 —— `runtime-parameters` 200、`oidc/token refresh_token` 200、`account/lifecycle` 200、
`capabilities` 200、**`WebSocket /diandian/ws/tts/volcengine` accepted**、火山 TTS 合成欢迎语成功、
`appcast-windows.xml` 200、遥测 batches 200，**全程无 500**。点点实际连 `127.0.0.1:56625 → 127.0.0.1:443`。
关掉点点后 xiaoliu 无影响。

### 不冲突
- 单实例锁：xiaoliu 是 `Global\xiaoliu.exe.single-instance`，点点另有自己的。
- 数据目录：`%LOCALAPPDATA%\xiaoliu` vs `%LOCALAPPDATA%\DiandianProd`。
- 服务端：`main.py` 无全局会话变量（请求级独立）；`asr.py`/`sapi_tts.py` 的 `_lock` **只保护模型懒加载**，
  不串行业务；`ark_tts.py` 无全局状态。
- 麦克风：Windows 录音设备共享模式，NAudio `WaveInEvent`（WinMM waveInOpen）可同时打开。

### 冲突（按严重度）
1. **热键撞车** —— xiaoliu `PushToTalkModifiers="Control,Alt"`（源码注释「照抄点点」），圈选 `Ctrl+Alt+S`；
   点点用 `PushToTalkGestureClassifier` 同款手势。**两边都用 `WH_KEYBOARD_LL` 低级钩子**（不是 RegisterHotKey），
   所以不抢系统热键注册，**两个钩子都会收到同一次按键** → 同时开录、同时发 ASR、两边都出字幕。
2. **麦克风双重采集** → 同一路音频录两遍，服务端跑两次 ASR。
3. **截图互相污染** —— xiaoliu 用 GDI `GetDC(0)`+BitBlt 抓全屏（`ScreenCapture.cs:74`，不排除任何窗口）
   → 点点的悬浮胶囊/字幕条会被一起发给模型；反向点点的 `Windows.Graphics.Capture` 也会拍到 xiaoliu 常驻胶囊。
4. **火山套餐 Key 并发 QPS** → 两边同时打 TTS/ASR 会互相挤，点点那边更敏感。

### 改热键的唯一办法（坑）
- 设置页「启动与热键」两个框是 `IsReadOnly="True"`（`WorkspaceWindow.xaml:209,212`）→ **只读，改不了**。
- `update_setting` 工具白名单里也没有热键（只有 text/image_retention_days、max_total_megabytes、show_cursor、show_asr_partial）。
- → 只能直接编辑 `%LOCALAPPDATA%\xiaoliu\settings.json` 的 `PushToTalkModifiers` / `SelectRegionModifiers` /
  `SelectRegionKey`，改完**重启 xiaoliu**。改完要立刻回读确认 —— 单测会覆盖这个文件。
