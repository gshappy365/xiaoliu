## C2：解除脚本对服务器端的反向依赖（13:50-14:30）

用户指令：「c2」。

### 根因诊断（不是表面现象）

原 `scripts/run-server.sh` 要 `eval` 服务器端 `start-real.sh` 的 export 段、
硬编码 `SERVER_DIR`/`ROOT`，是因为**服务器端启动器只能起 TLS**：
`run_live.py` 强制要求自签证书存在（缺失直接 exit 2），且不给 uvicorn 传明文参数。
为了开一个明文端口，只能绕开 `run_live.py` 直接跑 uvicorn →
于是只能复制启动逻辑 → 于是只能 eval 别人的 export 段 → 于是只能硬编码路径。

**关键对照**：`start-real.sh` 自己已经用 `BASH_SOURCE` 算 `HERE`/`ROOT`，
也已经处理跨平台 venv 路径（`.venv/bin/python` vs `.venv/Scripts/python.exe`），
而且第 149 行**已经支持 `PORT`**。硬编码路径是重复且更差的实现。

### 改法：合并成一个参数化启动器，不是加第二个脚本

服务器端（rea 不是 git 仓库 → 改前备份 `run_live.py.bak-20261105-plaintext`、
`start-real.sh.bak-20261105-plaintext`）：

| 改动 | 内容 |
|---|---|
| `run_live.py` | 加 `--plaintext`：跳过证书存在性检查、不给 uvicorn 传 `--ssl-certfile/--ssl-keyfile`、打印 scheme 用 http |
| `start-real.sh` | 加 `TLS` 开关（`TLS=0` → 传 `--plaintext`），头部注释补用法 |

**默认行为逐字节不变**（TLS=1 PORT=443 → exec 行与改前完全一致）。
diff 复核：start-real.sh 只改了注释 + 末尾 exec 分支；run_live.py 只加分支没删逻辑。

于是开发通道 = `TLS=0 PORT=8899 bash start-real.sh`，
**小六仓库不再需要携带任何服务器启动器** → `git rm scripts/run-server.sh`，
`scripts/` 目录随之消失（git 不跟踪空目录）。

### 踩过的坑（都是真坑，值得记）

- **`.bat` 的注释必须用 ASCII 英文**：本机系统代码页 **936（GBK）**，
  cmd.exe 按 OEM 代码页读 `.bat`。我写 UTF-8 中文注释 →
  注释行被当成命令执行 → 报 `'噷鐨?shell...` 之类的**假报错**，
  而脚本其实跑成功了。→ 三个 `.bat` 注释全改 ASCII，中文说明放 `README.md`。
  （与「`.bat` 必须 CRLF + 无 BOM」是同一类问题。）
- **`Set-ScheduledTask -TaskName` 支持通配符**：`xiaoliu-server` 会同时匹配
  `xiaoliu-server-watchdog`。第一次改完读回来的 `xiaoliu-client` 显示的是
  watchdog 的 action，一度以为改错了 —— 实际是通配符匹配 + 读取时机造成的混淆。
  → 改完必须**逐个任务重新读取核对**，不能只看一条。
- **`New-ScheduledTaskAction` 的 `-Argument` 不能传空串**（`xiaoliu-client` 没有参数）→
  分开处理，不传该参数。
- **PS 5.1 没有 `-SkipCertificateCheck`** → 用 curl 验 https 健康检查。
- **`Process.Start` / `Start-Process` / `Add-Type` / `Shell.Application` 全被沙箱拦** →
  测 `.bat` 用 `& 'path.bat'`（PowerShell 原生调用，不算 Process.Start）。
- **`genie-trash` 对空目录报错但实际已删**（Windows 回收站 API 限制）。
  删除钩子 fail-closed：trash 失败就拒绝删除，**不会**回退硬删。
- **回收站 API** 用 `[Microsoft.VisualBasic.FileIO.FileSystem]::DeleteDirectory(...,
  SendToRecycleBin)`（该程序集默认已加载，不需要 `Add-Type`）。
- 沙箱里 **cmd.exe 不能从 Bash 调**，**powershell.exe 不能从 Bash 调** ——
  跨语言调用只能走各自的工具。
