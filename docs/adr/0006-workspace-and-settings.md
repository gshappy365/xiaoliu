# ADR 0006：主工作区窗口与设置页

日期：2026-10-30
状态：已采纳

## 背景

到 v1 收尾时，小柳只有托盘图标、顶部胶囊、字幕条、指点层、圈选层。除了托盘菜单里的
「历史记录」，没有任何可以看和改的地方：改设置要手改 `settings.json`，看历史要开一个
单独的只读窗口，两者都不像成品。

用户提出「点点的前端主页面、设置界面也需要复刻到 xiaoliu.exe」。

## 决策

新增 `WorkspaceWindow`（主工作区），结构与点点 `MainWorkspaceWindow` 同构：

| 项 | 点点的做法 | 小柳的做法 |
|---|---|---|
| 窗口尺寸 | 1000 × 680 DIP，无边框 + 圆角 | 同（`WindowChrome` 圆角 12） |
| 左侧导航 | `NavigationView`，约 232 DIP | 自绘 232 DIP 列表 |
| 设置 | 是窗口里的一页，不是独立窗口 | 同 |
| 设置分类 | 左侧二级导航（`SettingsNavigation`）+ 窄窗口下的横向 tab | 左侧二级导航，150 DIP |
| 设置行 | `SettingsRow`：MinHeight 52、标题 13、描述 11（0.72 透明）、底边 0.5 线 | `SettingsRowControl` 照搬这套数值 |
| 开关 | `ToggleSwitch`，宽 72 | `CheckBox` 改模板成轨道 + 圆点，宽 72 |

页面三页：**对话**（打字提问 + 圈选/选图 + 当前画面 + 最近一轮）、**历史**、**设置**。

设置分七类，只映射到小柳真有的能力：

- **通用**：开机自启、按住说话键位、圈选键位、按住多久算说话、打字自检、日志与配置目录
- **语音**：录音设备、测试麦克风、音色、识别中间结果
- **模型**：模型标识、推理强度、每轮最多请求
- **外观**：常驻胶囊、回答跟着指点走、显示指点图形、图形预览
- **数据**：对话/截图留存天数、占用上限、当前占用、清空、打开数据目录
- **连接**：服务端地址、访问令牌、跳过证书校验、保存并测一次 `/healthz`
- **关于**：版本、它不会做什么（四条策略）、第三方组件

## 没有搬的部分

点点的账号、课程库、技能包、积分四个分类，小柳都没有对应能力，做成空面板就是死入口。
交接文档本来也把课程三件套和技能两件套排除在范围外（`rea/docs/adr/0005`）。
等这些能力真的有了再补分类，而不是先摆一个点不动的入口。

点点的 `CompanionCharacter`（会动的角色形象）和毛玻璃渐变材质也没搬，理由同 ADR 0005。

## 代价

- **多了一个窗口**。原来「小柳不占窗口位置」是刻意的（`TrayHost` 的注释写了）。现在主窗口
  只在用户主动打开时出现，关闭即销毁，托盘和热键照旧 —— 常驻形态没变。
- **配置整份读写**。设置页每改一项就 `Save()`，而 `AppSettings` 是整份序列化。这意味着
  运行期间手改 `settings.json` 会被覆盖（这个坑在 README 里已经写过一次）。要支持热改文件
  得加文件监听 + 合并，v1 不做。
- **设置项的生效时机不一致**：模型、音色、推理强度下一轮生效；胶囊显隐要重开；留存天数
  下次启动清理时才生效。界面上用 `CaptionStatus` 说明，但没有逐项标注。

## 顺带修掉的两个问题

1. **`ComboBox` 在深色面板上是空白**。默认模板的选中项用系统浅色主题的前景色（近黑），
   在 `#1B1E26` 上等于看不见。补了自带模板。
2. **回车发不出去**。`TextBox` 的类处理器先把 Enter 处理掉并标记 `Handled`，挂在 `KeyDown`
   上的处理器永远收不到。改挂 `PreviewKeyDown`。
